## ۱. پیش‌نیازها

- Node.js نسخه ۱۸.۱۸ یا بالاتر
- یک اکانت MongoDB (پیشنهاد: MongoDB Atlas، پلن رایگان M0 کافیه و از تراکنش پشتیبانی می‌کنه)
- ربات ساخته‌شده با @BotFather
- اکانت Vercel
- (اختیاری ولی توصیه‌شده) اکانت Sightengine برای مادیشن تصاویر

## ۲. نصب محلی

```bash
npm install
cp .env.example .env
```

بعد مقادیر `.env` رو طبق بخش بعد پر کن.

## ۳. متغیرهای محیطی (کامل)

| متغیر | الزامی؟ | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن از BotFather |
| `WEBHOOK_SECRET` | ✅ | رشته‌ی تصادفی خودت (`openssl rand -hex 32`) |
| `PUBLIC_URL` | فقط برای اسکریپت محلی | آدرس دیپلوی‌شده در Vercel |
| `MONGODB_URI` | ✅ | Connection String |
| `MONGODB_DB_NAME` | خیر (پیش‌فرض nava) | نام دیتابیس |
| `CRON_SECRET` | برای اطلاع‌رسانی تایم‌اوت جستجو | رشته‌ی تصادفی، Vercel خودکار به‌عنوان `Authorization: Bearer <این مقدار>` می‌فرسته |
| `SIGHTENGINE_API_USER` / `SIGHTENGINE_API_SECRET` | برای مادیشن عکس | از sightengine.com |
| `SIGHTENGINE_THRESHOLD` | خیر (پیش‌فرض 0.5) | امتیاز ریسک (۰ تا ۱) که بالاترش میره پیش ادمین |
| `STARS_PACKAGES` | خیر (پیش‌فرض داره) | قیمت‌های placeholder — فایل مشخصات قیمت واقعی نداده بود؛ قبل از production حتماً عوضش کن |
| `EMOJI_PREMIUM_*` (۴۰+ تا) | خیر | شناسه‌ی Premium Emoji؛ خالی بمونه، ایموجی معمولی جایگزین می‌شه |
| `ADMIN_IDS` | ✅ | آیدی عددی تلگرام ادمین(ها)، با کاما جدا |

## ۴. راه‌اندازی MongoDB

1. یه کلاستر بساز (Atlas M0 کافیه — رایگان و replica set هست، پس تراکنش‌ها کار می‌کنن).
2. یه دیتابیس یوزر بساز، Connection String رو بگیر، توی `MONGODB_URI` بذار.
3. Network Access رو یا `0.0.0.0/0` بذار (برای Vercel که IP ثابت نداره) یا از Atlas's Vercel integration استفاده کن.
4. ایندکس‌ها خودکار موقع اولین اجرای ربات ساخته می‌شن.

## ۵. راه‌اندازی در BotFather

- `/newbot` بزن، توکن رو بگیر
- `/setprivacy` روی Disable بذار
- برای Telegram Stars چیز اضافه‌ای لازم نیست، `currency: XTR` خودکار کار می‌کنه

## ۶. دیپلوی روی Vercel

1. پروژه‌ی `NAVA_BOT` رو به یه ریپازیتوری گیت‌هاب پوش کن
2. توی Vercel، پروژه‌ی جدید از همون ریپو بساز
3. همه‌ی متغیرهای بخش ۳ رو توی Project Settings تنظیم کن
4. Deploy کن

## ۷. تنظیم Webhook

```bash
npm run set-webhook
npm run webhook-info
npm run delete-webhook
```

## ۸. تنظیم Cron (محدودیت مهم)

`vercel.json` یه Cron هر ۲ دقیقه تعریف کرده که به کاربرهایی که جستجوشون تایم‌اوت شده اطلاع می‌ده.

پلن Hobby (رایگان) Vercel، Cron رو فقط روزی یه‌بار اجازه می‌ده. راه‌حل‌ها:
- ارتقا به پلن Pro
- یا یه سرویس مانیتورینگ رایگان بیرونی (مثل UptimeRobot) رو هر ۱-۲ دقیقه به `https://<domain>/api/cron/expire-searches` با هدر `Authorization: Bearer <CRON_SECRET>` بزن

## ۹. اولین راه‌اندازی بعد از دیپلوی

1. آیدی عددی تلگرامت رو به `ADMIN_IDS` اضافه کن (دوباره دیپلوی کن)
2. به ربات `/admin` بزن
3. «تنظیم کانال جوین اجباری» → کانال(ها) رو اضافه کن
4. «آیدی پشتیبانی» رو تنظیم کن
5. در صورت نیاز، متن‌های پیش‌فرض رو از پنل ادمین عوض کن

## ۱۰. راهنمای پنل ادمین (/admin)

- ویرایش راهنما ها: متن راهنما، راهنمای شماره یک، پیام پین، قوانین
- آیدی پشتیبانی
- تنظیم کانال جوین اجباری (تا ۱۰ تا)
- مدیریت رلیک کاربر
- ارسال پیام: فقط ناوبری آماده‌ست؛ منطق broadcast در پرامپت بعدی

عکس‌های مشکوک (پروفایل یا داخل چت) خودکار با دکمه‌ی تایید/رد برات میان.

## ۱۱. معماری و تصمیمات فنی مهم

- بدون state حافظه‌ای: همه‌چیز در MongoDB.
- همه‌چیز idempotent با شناسه‌های قطعی.
- تراکنش‌های MongoDB برای matchmaking و انتقال رلیک.
- آیدی ناشناس (anonId) به‌جای آیدی واقعی تلگرام.
- دکمه‌های Glass با فیلد واقعی style در Bot API 9.4.
- داده‌ی شهرها از sajaddp/list-of-cities-in-Iran (۳۱ استان، ۱۶۵۷ شهر).

## ۱۳. محدودیت‌های شناخته‌شده

- کد در محیط بدون اینترنت نوشته شده — تست زنده انجام نشده.
- قیمت‌های STARS_PACKAGES جایگزین (placeholder) هستن.
- دکمه‌های چت ایمن/درخواست چت/پیام دایرکت/افزودن مخاطب/بلاک/گزارش/اطلاع پایان چت/پیام همگانی فقط UI هستن.
- پاداش دعوت دوستان و تکمیل پروفایل: فقط معماری آماده‌ست.
- Premium Wallet: فقط پایه‌ی معماری مشترک — کد کامل Mini App طبق خود فایل، نسخه‌ی بعدیه.
- Cron روی پلن رایگان روزی یه‌بار محدوده.

## ۱۴. عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| ربات جواب نمی‌ده | npm run webhook-info بزن، last_error_message رو چک کن |
| خطای Transaction در MongoDB | باید replica set باشه (Atlas همیشه هست) |
| ایموجی پرمیوم نمایش داده نمی‌شه | EMOJI_PREMIUM_* رو با شناسه‌ی واقعی پر کن |
| مادیشن کار نمی‌کنه | SIGHTENGINE_API_USER/SECRET رو چک کن |
| Cron کار نمی‌کنه | پلن Hobby محدودیت داره + CRON_SECRET رو چک کن |
