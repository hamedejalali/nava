# ایمپورت هدیه از فایل (Gift Pack)

ادمین ← «نوا گرام» ← «🎁 هدیه‌ها و قیمت‌ها» ← **📥 ایمپورت از فایل** ← فایل را به‌صورت *File* بفرست.
بعد از ایمپورت، نام / قیمت / اموجی / اموجی پس‌زمینه‌ی هر هدیه را از همان صفحه‌ی هدیه تنظیم کن
(قیمت پیش‌فرض ایمپورت: ۱۰ XP). حداکثر ۶۰ هدیه در هر فایل، هر انیمیشن حداکثر ۲ مگابایت.

## فرمت‌های قابل قبول

| فایل | معنی |
|---|---|
| `.tgs` | یک انیمیشن تلگرام (همان فایل خروجی تلگرام، gzip‌شده‌ی Lottie) → یک هدیه |
| `.json` (Lottie) | یک انیمیشن Lottie (مثلاً از LottieFiles / After Effects + Bodymovin) → یک هدیه |
| `.json` (پک) | `{ "gifts": [ ... ] }` با انیمیشن داخل خود فایل (`lottie` / `tgs_b64` / `png_b64`) |
| `.zip` | `pack.json` + فایل‌های انیمیشن (`.tgs` / Lottie `.json` / `.png` / `.webp` / `.webm`). بدون `pack.json` هر فایل یک هدیه می‌شود |

## `pack.json`

```json
{
  "gifts": [
    { "file": "heart.json", "name": "قلب تپنده", "emoji": "❤️", "price": 20, "pattern": "💖", "c1": "#ff8fb1", "c2": "#c2185b" }
  ]
}
```

- `file` — نام فایل داخل zip (الزامی در پک zip)
- `name` (حداکثر ۲۴ حرف)، `emoji`، `price` (XP)، `pattern` (اموجی پس‌زمینه)، `c1` / `c2` (رنگ‌های گرادیان، `#rrggbb`) — همه اختیاری

## پک آماده

`gift-packs/starter-pack.zip` شش هدیه‌ی متحرک اصلی (قلب، ستاره، الماس، تاج، صاعقه، حلقه) دارد؛
با `node scripts/make-gift-pack.mjs` دوباره ساخته می‌شود و قابل ویرایش است.

## هدیه‌های خود تلگرام

ربات نمی‌تواند از بیرون فایل انیمیشن هدیه‌های تلگرام را دانلود کند؛ دو راه هست:
1. «➕ هدیه‌ی تلگرامی جدید» ← «🎁 هدیه‌های رسمی تلگرام» (از Bot API می‌گیرد، با همان انیمیشن اصلی)
2. استیکر انیمیشنی را مستقیم برای ربات بفرست، یا فایل `.tgs` آن را در «ایمپورت از فایل» بده.
