# اتصال Nava به ولت (Wallet) — جریان A «آدرس واریز»

از v1.26 فقط **جریان A** هست؛ جریان B (انتقال با توکن) حذف شد. Nava فقط «کلاینت» است.

## متغیرهای محیطی (فقط روی Vercel)
| نام | معنی |
|---|---|
| `WALLET_API_URL` | آدرس پایه‌ی API ولت (HTTPS) |
| `WALLET_INTEGRATION_ID` | شناسه‌ی اتصال |
| `WALLET_API_SECRET` | کلید مخفی |

## درخواست‌ها
هدرها: `Authorization: Bearer <ID>.<SECRET>`، `X-Wallet-Timestamp`، و `X-Wallet-Nonce` (جدید برای هر درخواست).

* `POST /deposit-codes` با `external_user_id` ← آدرس `JTX-XXXX-XXXX-XXXX-XXXX` برای هر کاربر (در `wallet_addresses` کش می‌شود).
* `GET /transfers?status=COMPLETED&completed_after=<cursor>&limit=100` ← واریزهای کامل‌شده. فیلتر شامل خودِ cursor است؛ تکراری‌ها با شناسه‌ی تراکنش حذف می‌شوند.

## جریان
۱. کاربر در منوی خرید «📥 آدرس ولت» را می‌زند؛ آدرسش نمایش داده می‌شود.
۲. تا وقتی روی آن صفحه است هر ~۵ ثانیه، و در کل سیستم حداکثر دقیقه‌ای یک‌بار (از webhook) و روزانه (cron)، واریزهای جدید خوانده می‌شوند.
۳. `delivered_amount` دقیقاً یک‌بار با شناسه‌ی دفتر `walletdep:<txId>` به ژتون کاربر اضافه می‌شود (تراکنش اتمیک).
۴. پیام «✅ X ژتون به حساب شما در نوا اضافه شد» به کاربر و رسید به کانال لاگ (مسیر «رسید واریز ولت»).
۵. خطای 401 فقط ساعتی یک‌بار به مالک اطلاع داده می‌شود.

پنل مالک «🔌 اتصال ولت»: وضعیت متغیرها ✅/❌، روشن/خاموش، آمار ۲۴ ساعت، ۱۰ واریز آخر، «همگام‌سازی همین الان».

## محدودیت صادقانه
با ولتِ شبیه‌سازی‌شده تست شده؛ با ولت واقعی تست نشده.
